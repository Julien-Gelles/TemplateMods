# 💎 Shiny Depths – Minecraft Mod

> A fantasy-themed mod that adds mystical gems, powerful armors, and stat-boosting accessories to enhance your Minecraft adventures.  
> ⚠️ **Work in Progress – Subject to heavy changes**



## 🧭 Overview

**Shiny Depths** is a Minecraft mod focused on expanding underground exploration and character progression.  
It introduces **rare gemstones**, **enchanted gear**, and **accessory systems** that offer **custom player stats**, paving the way for deeper RPG-style mechanics.


## 🚧 Development Status

The project is in active development and is **not yet stable or complete**.  
Core features and systems are being implemented progressively.

### ✅ Implemented

- Project structure initialized (Fabric mod)
- First custom items (e.g., basic gemstones)
- Initial creative tab integration

### 🛠️ In Progress / Planned

- 📦 New Ores & Gemstones (e.g., **sapphire**, **amethyst**, **obsidian crystal**)
- 🧤 Stat-boosting Accessories (rings, necklaces, etc.)
- 🛡️ Unique Armor Sets with passive effects
- ⚔️ Crafting recipes and balancing
- 🧙 RPG-style player attributes
- 🌌 Environmental additions (new underground features or biomes)


## 🎯 Project Vision

Shiny Depths is designed as a **modular RPG-like expansion**, enhancing both combat and progression while staying compatible with vanilla and other mods.

Key objectives:

- Bring **depth to mining** beyond vanilla ores
- Allow players to **specialize their playstyle** through equipment choices
- Lay groundwork for a **profession and stat system** (e.g., strength, agility)
- Create a **solid base mod** that could evolve into a full adventure experience


## 📦 Tech Stack

- Minecraft `1.20.1`
- [Fabric](https://fabricmc.net/)
- Written in **Java**
